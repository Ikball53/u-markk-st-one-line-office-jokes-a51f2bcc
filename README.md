## One-Line Office Jokes

Reply-all to 47 people begging to leave the thread — and now 46 of them are replying-all to say the same thing. Real office detail, laugh in the last words — 132 characters.

Entry line (132 characters): "I hit reply-all to 47 people begging to be removed from the thread, and now 46 of them are replying-all to say the exact same thing."

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
